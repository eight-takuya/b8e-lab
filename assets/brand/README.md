# Dreamin' Spiral Brand Design System

---

## Position

B8E および Dreamin' Spiral 全体のブランド資産を管理する入口である。

個別のブランド資産（OGP画像、ロゴ、配色、フォント、アイコン、図解、Web UIなど）はそれぞれ独立したディレクトリと README を持ち、詳細仕様は常に各資産の README を正とする。この `assets/brand/README.md` は、それらの資産がどこにあり、何を担っているかを一覧できる入口としてのみ機能する。

Brand OGP System（`assets/ogp/`）が、この Brand Design System における最初の正式資産である。

## Design Principles

Brand Design System全体を貫く思想は、以下の8つである。

- 静けさ
- 余白
- 自然
- 信頼
- 調和
- 呼吸感
- 一貫性
- 長く使える普遍性

個別資産ごとの詳細な適用方法は、各資産の README（例：`../ogp/README.md` の Design Philosophy）に記す。

---

## Governance

- 正式資産は1種類につき1つのマスターとする
- 派生マスター（v2・final・最新版など）は作らない
- 仕様書（README）と実体（マスターファイル・生成物）は同時に更新する
- 個別ページ・個別用途だけの場当たり的な例外対応は行わない
- 新しい表現が必要になった場合は、既存の構成を壊さず、正式な拡張として追加する
