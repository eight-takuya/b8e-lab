こんな感覚はありませんか？

エンジニアとして仕事をしてきた。

技術について考え、
問題を解き、
ものを創ることには慣れてきた。

でも最近、

  • 「もう少しProject全体を見てみたい」
  • 「顧客やBusinessにも関わってみたい」
  • 「自分で全部解くのではなく、チームで何かを創る仕事をしてみたい」

そんな感覚が、どこかにある。

一方で、
“管理職になる”と言われると、少し違う。

PMになって進捗管理ばかりするのも、
自分がやりたいこととは違う気がする。

もし、そんな感覚があるなら、
Project Creationは、ひとつの次の可能性かもしれません。

PMになることと、
Projectを創れるようになることは、同じではありません。

Projectを前に進めるために必要なのは、

進捗表を更新することだけでも、
会議を増やすことでも、
メンバーを管理することでもありません。

必要なのは、

  • 何が起きているのかを観ること。
  • 人の言葉を受け取ること。
  • その奥にあるIntentを捉えること。
  • 複雑な状況を構造化すること。
  • 必要な問いを置くこと。
  • そして、人と一緒に意思決定を生み出していくこと。

Project Creationでは、

「管理する人」になるのではなく、
Projectが動ける状態を創る人になる

ことを目指します。

3ヶ月後に目指す変化

Before

自分で考える。
自分で解決する。
自分で答えを出そうとする。

After

状況を観る。
人の言葉を受け取る。
Intentを捉える。
構造化する。
問いを置く。
人と答えを創る。
意思決定を生み出す。

自分で答えを抱え込むエンジニアから、
人と問いを交わしながら、
チームで答えを創れる人へ。

Projectを動かすための、新しい仕事のOS

  1. Observe起きていることを観る
  2. Receive人・事実・数字・違和感を受け取る
  3. Intentその奥にある目的や意図を見る
  4. Structure複雑な状況を構造化する
  5. Ask必要な問いを置く
  6. Decide意思決定を生み出す
  7. Natural Doing次の行動へつなげる

よくあるご質問

PM経験がなくても参加できますか？
参加できます。
エンジニアとしての経験を土台に、これからProject全体へ視野を広げたい方も対象です。
現在PMでも対象ですか？
対象です。
進捗管理だけになっている、ProductやBusinessまで視野を広げたい、人との関わり方を見直したい方にも適しています。
PM / PdM / PMOのどれを選ぶのですか？
最初から1つに決める必要はありません。
3つの視点を共通のProject Creation OSの上で体験します。
AI初心者でも大丈夫ですか？
大丈夫です。
AI機能を勉強することより、Projectの中で実際にAIと対話することを重視します。
自分のProjectがなくても参加できますか？
参加できます。
過去ProjectやCase Studyを利用できます。
毎週どのくらい時間が必要ですか？
Weekly Group Sessionが90分。
その他に60〜120分程度を目安に、実際の仕事の中でReal Workを行います。
機密情報はどう扱いますか？
所属企業・顧客・個人を特定できる情報をAIやGroupへそのまま持ち込まず、必要に応じて匿名化・抽象化します。
所属企業のPolicyを優先します。
録画はありますか？
Group Sessionは原則録画しません。
実案件やDialogueを安心して扱えることを優先します。
キャンセル・返金はできますか？
開講前であれば、全額返金します。
開講後は、原則として返金はありません。やむを得ない事情がある場合は、個別にご相談ください。
