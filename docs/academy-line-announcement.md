## 1. この配信の目的

**無料ガイドセッションの日程を、予約ページから自分で選べるようになったことを伝える。**

- 申し込みを増やすための配信ではない。**導線が開いたことを静かに知らせる**配信
- LINE の友だちは既に接点がある。**改まった営業文にしない**
- 読んだ人が「いまはタイミングではない」と判断することも、自然な結果として許容する

## 5. リンク先の選択

| 選択肢 | 遷移先 | 判断 |
|---|---|---|
| **LP（推奨）** | `https://www.b8e.co.jp/academy/session.html` | セッションの中身を読んでから日程選択へ進む。**当日の期待値がそろう** |
| 予約ページ直 | 予約ページ（公開 URL） | 摩擦は最小だが、**中身を読まずに申し込む**人が出る。無料ガイドセッションの性格に合わない |

→ **LP を推奨**。予約ページ直リンクは LINE には載せない。

### 流入元トラッキング（任意）

LP の Formspree hidden 項目 `source_page` は `?from=` の許可リストで検証している
（[academy-session-form-tracking.md](academy-session-form-tracking.md)）。
現在の許可リストに `line` は入っていないため、`?from=line` を付けても無視される（安全side だが計測されない）。

LINE 流入を分けて見たい場合のみ、`academy/session.html` の `ALLOWED` に `'line'` を足し、
リンクを `https://www.b8e.co.jp/academy/session.html?from=line` にする。
**必須ではない。** 計測が要らなければ現状のままでよい。

## 6. 書かないこと（NG）

| # | 書かない | 理由 |
|---|---|---|
| 1 | 「今だけ」「先着」「残りわずか」 | 希少性で動かす言い方をしない |
| 2 | 「ご検討ください」「お返事お待ちしています」 | 返信を求めない（Operation Pack §10-0） |
| 3 | Community / Premium の**料金** | セッション案内に料金は出さない。料金は場の中で必要になったときだけ |
| 4 | セッション後の流れを詳しく書く | LP の「セッションのあとに」で足りる |
| 5 | Zoom URL | 予約確定後の確認メールでのみ渡す |
| 6 | 「無料」の強調（太字・連呼） | 名称に含まれている。強調すると別の期待が立つ |
| 7 | 追い配信（一定期間後の再送） | 追いかけない方針（Operation Pack §10-A） |
